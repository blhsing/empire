# Empire.Core

`Empire.Core` 是不依賴視窗、GPU 或音效 API 的純 C# 即時戰略核心。所有公開玩家文字與資料沿用繁體中文；桌面前端只需呼叫指令方法，並以固定步長推進 `GameEngine`。

## 主要契約

- `GameData`：13 個文明、22 種單位、14 種建築、4 種難度與科技樹前置關係。
- `GameEngine.CreateNew`：建立 2～4 方戰局；單一邏輯更新為 `1/30` 秒。
- `GameEngine.Advance`：吸收真實經過時間並執行固定更新；`Step` 供測試與確定性模擬。
- `GameSaveService`：本機應用程式資料夾自動存檔，以及 JSON 匯入／匯出。讀取器接受瀏覽器 v1～v4 的已知文明與兵種識別碼。
- `GameState`：前端可唯讀繪製的完整戰局快照；命令必須透過 `GameEngine` 發出，以維護人口、成本與穩定 ID。

## 刻意的實作差異

- 路徑仍使用相同 58×42、八方向且禁止切角的網格，但開放集合改用 `PriorityQueue`，避免瀏覽器版線性掃描的成本。
- 粒子、浮字與音訊不是遊戲規則，不寫入存檔；載入後由前端重新產生。
- 即時採集直接計入玩家資源，與目前瀏覽器規則一致；模型保留 `Carrying` 欄位以便未來加入返庫機制。
- 存檔會保留命令與路徑，但重建生命、護甲、速度、人口等文明衍生值，避免舊版本數值污染目前平衡。

## 熱路徑原則

30Hz 更新以索引走訪現有清單，並在每刻開始時固定實體上限；當刻完成訓練的新單位會留待下一刻更新。因此不需要複製 `Entities`。王旗佔領使用引擎持有的四格計數緩衝區，文明軍令倍率也以具名方法查詢，避免每個單位、每一刻建立陣列、LINQ 列舉器或閉包。尋路及玩家指令仍可配置短命物件，因為它們不是每刻強制執行的工作。
