# Noto Sans TC

`NotoSansTC-VF.ttf` is the Traditional Chinese subset of Noto Sans CJK. It is
bundled with the native game so every supported desktop platform can render the
Traditional Chinese interface offline at 12 px or larger.

Source: https://github.com/notofonts/noto-cjk
